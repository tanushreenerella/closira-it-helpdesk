# ML results

Generated by the scripts in `backend/ml/`. Multi-task DistilBERT results (`multitask.json`,
`ood_multitask.json`) appear once it is trained (GPU / `train_colab.ipynb`); everything
below is from the baselines.

| File | Produced by |
|---|---|
| `data_stats.json` | `data.build_datasets` — sizes per source, label, split; dedupe counts |
| `abcd_stats.json` | `data.build_abcd` — per-split turn counts, rule hit counts |
| `baselines.json`, `baselines_per_class_f1.csv` | `baselines` — test-split macro-F1 + per-class F1 |
| `ood_tfidf_logreg.json` | `evaluate_ood` — 616 legacy IT messages |

## In-domain test split (macro-F1)

| Task | Keyword rules | TF-IDF + LogReg |
|---|---|---|
| Intent (7 classes, 4,982 test rows) | 0.592 | 0.967 |
| Emotion (6 classes, 3,998 test rows) | 0.403 | 0.539 |

Per-class F1 for TF-IDF/LogReg — intent: information_request 0.96, issue_report 0.94,
action_request 0.95, complaint 0.99, feedback 0.99, appreciation 0.99, chit_chat 0.96.
Emotion: angry 0.47, frustrated 0.36, confused 0.39, sad 0.58, happy 0.76, neutral 0.67.

**Caveats.**
- complaint / feedback / appreciation labels come from TWCS keyword rules, so a model can
  score near-perfectly by re-learning those keywords; their in-domain F1 overstates real
  performance until `data/review/twcs_review_200.csv` is hand-checked.
- The other intents are separated partly by *source domain* (banking vs. assistant
  commands vs. tweets), which also inflates in-domain intent F1.
- Emotion is the hard task: GoEmotions is Reddit text and frustrated/confused are small.

## Out-of-domain: 616 legacy IT-helpdesk messages

Gold = legacy label != `normal` (462 of 616 should escalate). Router = what the pipeline
does in the FAQ stage.

| | Precision | Recall | F1 |
|---|---|---|---|
| Keyword rules only | 0.987 | 0.331 | 0.496 |
| Model (TF-IDF) risk only | 0.894 | 0.310 | 0.460 |
| Router (rules + model) | 0.930 | 0.517 | 0.665 |

Escalation rate by legacy label (router): explicit_human_request 0.62, frustrated 0.74,
repeated_confusion 0.19, normal 0.12 (false alarms). Repeated confusion is the gap — it
is a multi-turn signal the per-turn model can't see (no conversation-level model yet).
